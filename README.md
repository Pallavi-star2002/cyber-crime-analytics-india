# 🛡️ Cyber Crime Analytics: India (2021–2023)

A comprehensive **Power BI dashboard** that analyzes cyber crime trends across India using data from the **National Crime Records Bureau (NCRB) – Crime in India Reports (2021–2023)**.

## 🎯 Project Objective

The objective of this project is to transform raw NCRB cyber crime data into an interactive Power BI dashboard that helps users analyze cyber crime trends, identify high-risk states and cities, understand crime motives, and evaluate law enforcement performance through key metrics and visual insights.

## 🚀 Key Features

* 📈 Year-wise cyber crime trend analysis (2021–2023)
* 🗺️ State & city-wise cyber crime analysis
* 🎯 Motive-wise breakdown of cyber crime cases
* ⚖️ Police disposal and chargesheeting rate analysis
* 🔍 Interactive filters and drill-down capabilities
