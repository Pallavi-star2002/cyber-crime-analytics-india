
# Cyber Crime Analytics: India (2021-2023)

Power BI dashboard analyzing cyber crime trends, motives, law enforcement 
response, and city-wise data across India using NCRB Crime in India reports.

## Features
- State & city-wise cyber crime trend analysis (2021-2023)
- Motive breakdown analysis
- Police disposal & chargesheeting rate tracking
- City-level drill-down dashboard

## Data Source
National Crime Records Bureau (NCRB) - Crime in India 2023 report

## Tools Used
Power BI, DAX, Power Query
